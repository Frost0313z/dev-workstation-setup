# 리눅스 실습 명령 (Ubuntu 터미널에서 칠 것)

작성 2026-11-02. 프롬프트가 `msong@...:~$` 인 Ubuntu 창에서 **한 줄씩** 친다.
`#` 뒤는 설명이라 안 쳐도 된다. 결과가 예상과 다르면 그 화면을 캡처해 둔다 (트러블슈팅 재료).

---

## 0. 녹화 켜기 (한 번만)

`script` 는 이후 치는 명령과 출력을 전부 파일에 담아 준다. 과제 로그를 손으로 복사할 필요가 없다.

```bash
mkdir -p ~/codyssey/logs
script ~/codyssey/logs/03-터미널-실습.log
```

이제부터 치는 모든 것이 기록된다. 실습이 끝나면 `exit` 한 번으로 녹화가 끝난다 (2절 끝 참고).

## 1. 터미널 기본 조작

과제 요구: 현재 위치 확인, 목록 확인(숨김 포함), 이동, 생성, 복사, 이동/이름변경, 삭제, 파일 내용 확인, 빈 파일 생성.

```bash
pwd                              # 현재 위치. /home/msong 이 나와야 한다
ls -la                           # 숨김 파일 포함 목록. .bashrc 같은 . 파일이 보인다

mkdir -p ~/codyssey/practice     # 폴더 생성. -p 는 중간 폴더까지 한 번에
cd ~/codyssey/practice           # 이동
pwd                              # /home/msong/codyssey/practice 확인

touch memo.txt                   # 빈 파일 생성
echo "hello linux" > hello.txt   # 내용 있는 파일 생성
cat hello.txt                    # 파일 내용 확인 → hello linux
cat memo.txt                     # 빈 파일이라 아무것도 안 나온다

cp hello.txt copy.txt            # 복사
mv copy.txt renamed.txt          # 이름 변경 (mv 는 이동과 이름변경 둘 다)
mkdir sub                        # 하위 폴더 생성
mv renamed.txt sub/              # 폴더로 이동
ls -la                           # memo.txt, hello.txt, sub/ 가 보인다
ls -la sub                       # renamed.txt 가 sub 안에 있다

rm sub/renamed.txt               # 파일 삭제
rm -r sub                        # 폴더 삭제 (-r 은 안의 것까지)
ls -la                           # sub 가 사라졌다
```

### 절대 경로 / 상대 경로 확인 (시험 포인트)

```bash
cd ~/codyssey/practice
cat /home/msong/codyssey/practice/hello.txt   # 절대 경로: 어디서 쳐도 같은 파일
cat ./hello.txt                               # 상대 경로: 현재 폴더 기준
cat ../practice/hello.txt                     # 상대 경로: 한 단계 위로 갔다가 다시
cd /tmp
cat ./hello.txt                               # 실패해야 정상. 현재 위치가 바뀌었으니까
cat /home/msong/codyssey/practice/hello.txt   # 절대 경로는 여전히 된다
cd ~/codyssey/practice
```

## 2. 권한 실습

과제 요구: 파일 1개 + 디렉토리 1개, 변경 **전/후** 비교.

### 2-1. 파일 권한

```bash
cd ~/codyssey/practice
echo 'echo "script ran"' > run.sh   # 실행할 스크립트 파일
ls -l run.sh                        # 변경 전. -rw-r--r-- (644) 가 보통
./run.sh                            # Permission denied 가 나와야 정상. x 가 없으니까

chmod 755 run.sh                    # 소유자 rwx, 그룹 r-x, 기타 r-x
ls -l run.sh                        # 변경 후. -rwxr-xr-x
./run.sh                            # 이제 실행된다 → script ran

chmod 644 run.sh                    # 다시 되돌리기
ls -l run.sh                        # -rw-r--r--
./run.sh                            # 다시 Permission denied
```

### 2-2. 디렉토리 권한

```bash
mkdir secret
echo "inside" > secret/note.txt
ls -ld secret                       # 변경 전. drwxr-xr-x (755). 맨 앞 d 는 디렉토리

chmod 000 secret                    # 모든 권한 제거
ls -ld secret                       # d---------
ls secret                           # Permission denied (r 없음)
cat secret/note.txt                 # Permission denied (x 없어서 안으로 못 들어감)

chmod 755 secret                    # 복구
ls -ld secret                       # drwxr-xr-x
cat secret/note.txt                 # inside
```

### 2-3. 숫자 말고 글자로도 바꿔 보기

```bash
chmod +x run.sh                     # 모두에게 x 추가
ls -l run.sh                        # -rwxr-xr-x
chmod o-r run.sh                    # 기타(o)에서 r 제거
ls -l run.sh                        # -rwxr-x--x
chmod 644 run.sh                    # 정리
```

### 녹화 끝내기

```bash
exit                                # script 녹화 종료. "Script done" 이 뜬다
ls -l ~/codyssey/logs               # 03-터미널-실습.log 가 생겼다
```

## 3. 로그를 과제 저장소로 가져오기

Ubuntu 안에서 Windows 폴더는 `/mnt/c/...` 로 보인다.

```bash
cp ~/codyssey/logs/03-터미널-실습.log /mnt/c/Users/msong/orca/projects/Setting/logs/
```

VSCode 에서 `logs/03-터미널-실습.log` 가 보이면 성공.

## 자주 나는 실수

| 증상 | 원인 | 해결 |
|---|---|---|
| `command not found` | 오타, 또는 PowerShell 창에서 침 | 프롬프트가 `msong@` 로 시작하는지 확인 |
| `No such file or directory` | 현재 위치가 다름 | `pwd` 로 위치 확인 후 `cd` |
| `Permission denied` (의도 안 했는데) | 권한 실습 중 복구 안 함 | `chmod 755 파일` |
| `rm` 했는데 폴더가 안 지워짐 | 폴더는 `-r` 필요 | `rm -r 폴더` |
| 한글 파일명이 `???` 로 보임 | 터미널 인코딩 | Windows Terminal 을 쓰면 안 생김 |
